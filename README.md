# Python Crash Course

My worked exercises from *Python Crash Course* by Eric Matthes — the "Try It Yourself" exercises, one file per exercise.

This is the starting point: for now it's just the basic exercises as I work through the book. Commentary and notes to accompany future videos will be added here later.

## Layout

Files are named `exercise_<chapter>_<number>.py`, e.g. `exercise_3_4.py` is exercise 3-4.

| Chapter | Topic | Exercises |
|---|---|---|
| 1 | Getting started | 1-1 – 1-4 |
| 2 | Variables and simple data types | 2-1 – 2-11 |
| 3 | Introducing lists | 3-1 – 3-11 |
| 4 | Working with lists | 4-1 – 4-13 |
| 5 | if statements | 5-1 – 5-13 |

`scratchpad.py` is a place for trying things out.

## Running

Requires Python 3.14+. Run any exercise directly:

```bash
python exercise_2_3.py
```

or with [uv](https://docs.astral.sh/uv/):

```bash
uv run exercise_2_3.py
```
